# Prompt 子命令文档

`micro prompt` (简写 `micro p`) 是一个智能提示词优化工具，帮助您将原始提示词优化成更清晰、更有效的版本。

## 🚀 核心功能

### 基础优化功能
- **智能优化**：基于大语言模型优化提示词
- **多种输入方式**：支持直接文本、文件输入、标准输入
- **流式输出**：实时显示优化结果
- **上下文感知**：可以提供额外上下文信息

### 🆕 交互式会话模式
- **对话历史**：自动记住当前会话中的完整对话历史
- **智能记忆管理**：自动压缩长对话历史，保留重要信息
- **上下文感知优化**：基于对话历史提供更精准的优化建议
- **持续对话**：保持对话连续性，直到用户明确表示退出

## 📖 使用指南

### 基本用法

```bash
# 直接文本优化
micro p "请帮我写一个函数"

# 文件输入
micro p ./prompt.txt

# 标准输入
echo "提示词" | micro p -

# 交互模式
micro p -i
micro p --interactive
```

### 交互模式详细说明

进入交互模式后，您可以：
1. 连续输入多个提示词进行优化
2. 系统会记住之前的对话内容
3. 基于历史对话提供更精准的优化建议
4. 输入 `exit`、`quit` 或 `退出` 结束会话

## 🔧 高级配置

### 存储后端选择

系统支持多种存储后端：

#### 内存存储（默认）
- 适用于开发和测试
- 无需额外配置
- 会话数据不持久化

#### MySQL 存储
- 适用于生产环境
- 数据持久化
- 支持事务

#### Redis 存储
- 适用于高并发场景
- 支持分布式部署
- 高性能缓存

### 构建选项

```bash
# 默认构建（仅内存存储）
go build -o micro ./cmd/micro

# 包含MySQL支持
go build -tags mysql -o micro ./cmd/micro

# 包含Redis支持
go build -tags redis -o micro ./cmd/micro

# 包含所有存储支持
go build -tags "mysql redis" -o micro ./cmd/micro
```

## 🚨 注意事项

### API 配置
使用前请确保配置了有效的API密钥：
- 阿里云 DashScope API 密钥
- 或阿里百炼 API 密钥

### 性能考虑
- 交互模式会消耗更多内存来存储对话历史
- 长时间会话可能触发记忆压缩
- 建议定期结束会话以释放资源

### 最佳实践
- 在交互模式中提供清晰的上下文信息
- 合理使用会话功能，避免无关对话混杂
- 定期查看日志了解系统行为
