# 交互式提示词优化演示

## 功能概述

新的交互式会话模式为 `prompt` 命令增加了强大的对话记忆功能，让您可以在单次会话中进行连续的提示词优化，系统会记住对话历史并提供更精准的优化建议。

## 核心特性

### 🧠 对话记忆
- 自动记住当前会话中的完整对话历史
- 保存用户输入和助手回复
- 为每条消息添加时间戳

### 🗜️ 记忆压缩
- 当对话轮次较多时（默认超过8条消息），主动对早期对话进行智能总结
- 保留重要细节：关键决定、用户偏好、重要事实等
- 压缩时保持对话的核心信息和上下文连贯性

### 🔄 持续对话
- 保持对话连续性，直到用户明确表示退出
- 支持多种退出命令：`exit`、`quit`、`退出`、`q`、`bye`、`再见`

### 🎯 上下文感知优化
- 基于对话历史提供更精准的优化建议
- 理解用户的偏好和需求模式
- 避免重复相同的建议

## 使用方法

### 启动交互模式

```bash
# 使用短参数
micro p -i

# 使用长参数
micro p --interactive
```

### 交互流程示例

```
🤖 欢迎使用提示词优化交互模式！
💡 特性：保持对话历史、智能记忆压缩、上下文感知优化
📝 输入您的提示词，我将为您优化。输入 'exit'、'quit' 或 '退出' 结束会话。
------------------------------------------------------------

💬 请输入提示词: 帮我写一个函数

🔄 正在优化提示词...
[AI 优化结果显示...]

📊 会话统计: 2条消息
------------------------------------------------------------

💬 请输入提示词: 这个函数需要处理大数据

🔄 正在优化提示词...
[AI 基于之前对话历史的优化结果...]

📊 会话统计: 4条消息
------------------------------------------------------------

💬 请输入提示词: exit

👋 感谢使用！会话已结束。
```

## 技术实现

### 会话管理器
- `session.Manager`: 核心会话管理组件
- `session.Session`: 单个会话实例
- `session.Message`: 消息结构

### 记忆压缩算法
- 当消息数超过阈值时自动触发
- 智能提取对话主题和关键点
- 生成简洁但信息丰富的摘要

### 上下文构建
- 结合会话摘要和最近对话
- 为 LLM 提供结构化的上下文信息
- 优化 token 使用效率

## 配置选项

### 默认设置
- 最大消息数：8条（4轮对话）
- 压缩触发：超过最大消息数时
- 保留消息：压缩后保留最近4条消息

### 自定义配置
可以通过修改 `session.NewManager()` 的参数来调整：
- `maxMessages`: 最大消息数阈值
- 退出命令列表
- 欢迎消息和提示符

## 最佳实践

### 适用场景
1. **迭代优化**：需要多轮优化同一个提示词
2. **主题探索**：围绕特定主题进行深入讨论
3. **学习模式**：通过对话学习提示词优化技巧

### 使用建议
1. 在交互模式中保持话题的连贯性
2. 利用对话历史，逐步细化需求
3. 观察会话统计，了解对话进展
4. 适时使用退出命令结束会话

## 故障排除

### 常见问题
1. **输入为空**：系统会提示重新输入
2. **优化失败**：显示错误信息，可继续对话
3. **记忆压缩**：自动进行，用户无需干预

### 调试信息
- 会话统计显示当前状态
- 日志记录详细的会话活动
- 错误信息提供用户友好的提示
