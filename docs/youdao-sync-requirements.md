# micro youdao 同步需求

## 背景与目标

本地用编辑器修改 Markdown 笔记之后，希望一条命令就把改动同步到有道云笔记，不必打开客户端手动复制粘贴。

`micro youdao` 是 microdev 的新子命令，别名 `y`。它调用有道官方的 `youdaonote` CLI 完成云端读写，自己只负责本地文件扫描、变更判断和映射记录。

完成标准：同一个本地文件第一次同步会在云端创建笔记，之后每次内容变化都更新同一篇云端笔记，内容没变则不做任何云端调用。

## 范围

本期包含：

- 本地到云端的单向同步。
- 只处理 `.md` 文件，原因是官方 `update` 只支持 Markdown 笔记。
- 单文件和目录两种输入，缺省时使用默认目录。
- 变更检测、dry-run、指定云端目录。

本期不包含：

- 云端到本地的拉取。
- 冲突检测与合并。
- 后台监听文件变化自动同步。
- 本地文件删除后同步删除云端笔记。
- 附件、图片等非 Markdown 内容。
- 待办、网页收藏等有道其他能力。

## 前置依赖

- 本机已安装官方 `youdaonote` CLI，并执行过 `youdaonote config set apiKey <API Key>`。API Key 在有道 MCP 控制台获取，账号需要先绑定手机号。
- 假设：`youdaonote create --json` 的输出包含新笔记的 fileId。联调时必须用真实命令验证；若拿不到，改为按标题调用 `list --json` 反查，需求 YD-203 随之调整。

## 配置

环境变量名与默认值放在 `infra/consts`，解析与校验放在 `component/config`，非法值回退到默认值。

| 环境变量 | 默认值 | 作用 |
| --- | --- | --- |
| `MICRO_YOUDAO_DIR` | `~/youdao-notes` | 默认同步目录，命令不带路径参数时使用 |
| `MICRO_YOUDAO_BIN` | `youdaonote` | 官方 CLI 的可执行文件名或绝对路径 |

## 命令形态

```bash
micro youdao                    # 同步默认目录下有改动的 .md
micro youdao ./notes            # 同步指定目录
micro youdao ./notes/todo.md    # 同步单个文件
micro youdao --dry-run          # 只打印将要执行的操作
micro youdao --folder <folderID> # 首次创建时放入指定云端目录
micro youdao todo.md -n "标题"   # 单文件时覆盖笔记标题
```

## 需求条目

优先级含义：P0 为没有它功能不成立，P1 为影响日常使用，P2 为可后置。

### 输入与目录

| 编号 | 优先级 | 触发条件 | 预期行为 | 异常处理 |
| --- | --- | --- | --- | --- |
| YD-101 | P0 | 不带路径参数执行 | 使用 `MICRO_YOUDAO_DIR` 作为同步目录 | 目录不存在时报错并提示创建或设置环境变量，不自动创建 |
| YD-102 | P0 | 参数是目录 | 递归扫描其中所有 `.md` 文件，跳过以 `.` 开头的文件和目录 | 目录无任何 `.md` 时提示无可同步内容，退出码为 0 |
| YD-103 | P0 | 参数是 `.md` 文件 | 只同步该文件 | 参数既不是目录也不是 `.md` 文件时报错并退出 |
| YD-104 | P1 | 环境变量值非法 | 回退到默认值，不终止程序 | 回退时写一条 warn 日志 |

### 映射与变更检测

| 编号 | 优先级 | 触发条件 | 预期行为 | 异常处理 |
| --- | --- | --- | --- | --- |
| YD-201 | P0 | 同步过任一文件 | 在同步目录下写入映射文件 `.micro-youdao.json`，记录相对路径、云端 fileId、最近同步内容的 sha256 | 映射文件损坏时报错并指出路径，不覆盖，不猜测重建 |
| YD-202 | P0 | 文件内容哈希与映射记录一致 | 视为无改动并跳过，不调用云端 | 无 |
| YD-203 | P0 | 映射中没有该文件 | 调用 `create` 创建笔记，成功后写入 fileId 与哈希 | 创建成功但解析不到 fileId 时报错，并提示云端可能已存在该笔记，需要人工处理 |
| YD-204 | P0 | 映射中有该文件且哈希变化 | 调用 `update <fileId>` 更新内容，成功后更新哈希 | 云端返回笔记不存在时报错，不自动改为 create，由用户决定是否清除该映射项 |
| YD-205 | P1 | 笔记标题 | 默认取不含扩展名的文件名，`-n` 仅在单文件输入时允许覆盖 | 目录输入同时传 `-n` 时报错 |
| YD-206 | P1 | 目录同步中单个文件失败 | 继续处理其余文件，最后汇总成功、跳过、失败的数量 | 只要有失败，退出码非 0；失败文件不更新映射 |

### 云端目录

| 编号 | 优先级 | 触发条件 | 预期行为 | 异常处理 |
| --- | --- | --- | --- | --- |
| YD-301 | P1 | 首次创建且传了 `--folder` | 笔记创建到指定云端目录 | 官方 CLI 报目录无效时原样转述其错误信息 |
| YD-302 | P1 | 已同步过的文件再传 `--folder` | 忽略该参数并提示笔记已存在，不做移动 | 无 |

### 预演与输出

| 编号 | 优先级 | 触发条件 | 预期行为 | 异常处理 |
| --- | --- | --- | --- | --- |
| YD-401 | P1 | 传 `--dry-run` | 逐个文件打印将执行 create、update 还是跳过，不调用官方 CLI，不写映射文件 | 无 |
| YD-402 | P1 | 同步结束 | 在终端输出每个文件的结果和汇总，用户可见输出走 `infra/console` | 无 |
| YD-403 | P2 | 同步过程 | 结构化日志走 `infra/logger`，输出到标准错误，Msg 使用英文 | 无 |

### 官方 CLI 调用

| 编号 | 优先级 | 触发条件 | 预期行为 | 异常处理 |
| --- | --- | --- | --- | --- |
| YD-501 | P0 | 任意云端操作 | 通过 `os/exec` 调用 `MICRO_YOUDAO_BIN`，加 `--json` 解析输出 | 找不到可执行文件时报错，并提示安装方式与 `config set apiKey` 步骤 |
| YD-502 | P0 | CLI 返回非 0 退出码 | 将 CLI 的标准错误原样附在错误信息里 | 认证失败等错误不重试 |
| YD-503 | P1 | 用户按 Ctrl+C | 取消传给子进程，终止当前调用 | 被取消的文件不更新映射 |
| YD-504 | P1 | 测试 | 对官方 CLI 的调用封装成接口，测试用假实现替换，默认 `go test ./...` 不依赖真实有道账号 | 无 |

## 目录落点

```text
cmd/micro/main.go                  注册 youdao 子命令
component/youdao/api/              cobra 命令，只做参数与输出适配
component/youdao/service/          扫描、变更判断、同步编排
component/youdao/store/            映射文件读写
infra/youdao/                      官方 CLI 调用封装
infra/model/youdao/                领域模型与 Param、Response
infra/consts/                      命令名、环境变量名、默认值
component/config/                  环境变量解析与校验
```
