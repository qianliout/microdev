# Translate 子命令文档

`micro translate` (简写 `micro t`) 是一个智能中英互译工具，支持自动语言检测和批量翻译功能。

## 🌐 核心功能

### 智能翻译
- **自动语言检测**：智能识别中文和英文内容
- **中英互译**：中文自动翻译为英文，英文自动翻译为中文
- **上下文保持**：保持原文的格式和结构
- **高质量输出**：基于大语言模型的高质量翻译

### 多种输入方式
- **直接文本翻译**：命令行直接输入文本
- **文件翻译**：支持单个文件翻译
- **目录批量翻译**：支持整个目录的批量翻译
- **标准输入**：支持管道输入

### 🆕 高级功能
- **翻译幂等性**：自动检测已翻译文件，避免重复翻译
- **并发翻译**：支持多文件并发处理，提高效率
- **多格式支持**：支持 Markdown、文本、代码文件等多种格式
- **强制重译**：可选择强制重新翻译已存在的文件

## 📖 使用指南

### 基本用法

```bash
# 直接文本翻译
micro t "Hello, World!"
micro t "你好，世界！"

# 文件翻译
micro t ./document.md
micro t ./readme.txt

# 标准输入
echo "Hello" | micro t -
cat document.md | micro t -
```

### 目录批量翻译

```bash
# 翻译目录下所有 Markdown 文件
micro t -d ./docs

# 翻译目录下所有 txt 文件
micro t -d ./docs -t txt

# 翻译目录下所有 Go 文件
micro t -d ./src -t go

# 使用并发翻译（5个并发）
micro t -d ./docs -c 5

# 强制重新翻译已存在的文件
micro t -d ./docs --force
```

### 输出文件管理

```bash
# 指定输出文件
micro t input.md -o output.md

# 自动生成输出文件名
# 中文文件 -> 英文文件：document.md -> document_en.md
# 英文文件 -> 中文文件：readme.md -> readme_zh.md
micro t document.md
```

## 🔧 命令选项

### 基本选项
- `-d, --directory`: 指定要翻译的目录
- `-t, --type`: 指定文件类型过滤（如 md, txt, go）
- `-o, --output`: 指定输出文件路径
- `-c, --concurrency`: 设置并发数量（默认为3）
- `--force`: 强制重新翻译已存在的文件

### 使用示例

```bash
# 基础翻译
micro t "This is a test"

# 文件翻译
micro t ./README.md

# 目录翻译，只处理 Markdown 文件
micro t -d ./docs -t md

# 高并发批量翻译
micro t -d ./docs -c 10

# 强制重译所有文件
micro t -d ./docs --force
```

## 🎯 功能特性详解

### 🔄 翻译幂等性

系统会自动检测翻译文件是否已存在：
- 中文文件 `document.md` → 检查 `document_en.md` 是否存在
- 英文文件 `readme.md` → 检查 `readme_zh.md` 是否存在
- 如果目标文件已存在，默认跳过翻译
- 使用 `--force` 参数可强制重新翻译

### ⚡ 并发翻译

支持多文件并发处理：
- 默认并发数：3
- 可通过 `-c` 参数调整并发数
- 适合大量文件的批量翻译
- 自动负载均衡，避免API限流

### 📁 智能文件处理

- **格式保持**：保持原文件的格式和结构
- **编码处理**：自动处理不同文件编码
- **路径管理**：智能生成输出文件路径
- **错误恢复**：单个文件失败不影响其他文件

## 🌟 支持的文件类型

### 文档类型
- **Markdown** (`.md`): 保持Markdown格式
- **文本文件** (`.txt`): 纯文本翻译
- **HTML** (`.html`): 保持HTML结构

### 代码文件
- **Go** (`.go`): 翻译注释，保持代码不变
- **Python** (`.py`): 翻译注释和文档字符串
- **JavaScript** (`.js`): 翻译注释内容

### 配置文件
- **YAML** (`.yml`, `.yaml`): 翻译值，保持结构
- **JSON** (`.json`): 翻译字符串值
- **TOML** (`.toml`): 翻译配置说明

## 🔍 语言检测机制

系统使用智能语言检测：

### 检测规则
1. **中文检测**：包含中文字符（汉字、中文标点）
2. **英文检测**：主要为英文字符和标点
3. **混合内容**：根据主要语言确定翻译方向
4. **特殊处理**：代码、数字、符号保持不变

### 检测示例
```bash
# 中文 → 英文
"你好，世界！" → "Hello, World!"

# 英文 → 中文  
"Hello, World!" → "你好，世界！"

# 混合内容
"Hello 世界" → 根据主要语言确定方向
```
